# 产物验证

`apps/ios/scripts/verify-ipa.cjs` 是 IPA 的自动化验收器。CI 的 `verify`
job 会在每次构建后自动跑它 —— 不通过就让整个 run 变红。

存在的理由：这个项目里已经出现过**两次「日志 success 但产物不对」**
（bsdtar 参数不兼容被 `continue-on-error` 吞掉、busybox 校验正则永远
匹配不到被 `::warning::` 吞掉）。人眼看日志不可靠，所以改成机器断言。

## 用法

```bash
# 直接验 ipa
node apps/ios/scripts/verify-ipa.cjs apps/ios/out/CoomiIOS-unsigned.ipa

# 也支持验 CI 下载下来的 zip（自动解出里面的 ipa）
node apps/ios/scripts/verify-ipa.cjs ~/Downloads/CoomiIOS-unsigned.zip
```

退出码 0 = 全过；1 = 有断言失败；2 = 验证器自身异常。

## 31 项断言

不依赖 macOS 工具链（不需要 `otool` / `nm` / `unzip`），zip、tar、gzip、
bplist、Mach-O 全部手工解析，所以在 Linux 和 Windows 上同样能跑。

| 组 | 断言 |
|---|---|
| 结构 | `Payload/*.app` 存在；主二进制存在且与 `.app` 同名 |
| Mach-O | 魔数 `0xFEEDFACF`、`CPU_TYPE_ARM64`、`MH_EXECUTE`、64 位 |
| C ABI | `coomi_start` / `coomi_port` / `coomi_version` 在二进制内 |
| 前端 | `web/index.html` 存在；前端在 `web/` 子目录；根目录无 `index.html` 与 chunk 残留；`web/assets/` 存在 |
| rootfs | `linux-rootfs.tar.gz` 存在、是有效 gzip、含 `bin/busybox`(919KB)、含 `bin/sh` 符号链接、含 `/workspace`、**uid/gid 全为 0** |
| 签名 | 无 `_CodeSignature`、无 `embedded.mobileprovision`（预期未签名） |
| Info.plist | 能解析（含 bplist00 二进制）；`CFBundleIdentifier` 合法；`CFBundleExecutable` 与实际一致；`MinimumOSVersion`；平台 `iPhoneOS`；`NSAllowsLocalNetworking` |

## 为什么断言这么写

**Mach-O 与符号**：iOS 上引擎是**进程内静态链接**的，所以
`libcoomi_ui.a` 的符号必须真的落到主二进制里。只要 `coomi_start` 不在，
Swift 侧 `dlsym`/直接调用就会崩 —— 这是"编译成功但运行必崩"的典型，
必须在打包阶段拦住。

**`web/` 与根目录污染**：引擎在 `ios_ffi.rs` 里把静态目录写死为
`home.join("web")`，且 `ServeDir` 指向它。若前端平铺到 `.app` 根，
`ServeDir` 就找不到文件 → **白屏**。XcodeGen 里必须写 `type: folder`。

**rootfs 的 uid/gid**：iSH 的 fakefs 以 uid/gid 映射宿主目录权限。
归档里若出现非 0 的 uid/gid（比如 macOS 打包时带进 `501:20`），
guest 内会出现"文件存在但读不了"或 git 报 `dubious ownership`。

**bplist**：Xcode 编译会把 `Info.plist` 转成 `bplist00` 二进制。
按 XML 正则找 key 会**找不到任何东西**，从而误报缺字段。
验证器内置了 bplist object table 解析。

## 实测基线

`0fe4235` 之前的 `3e61e87` 产物：

```
输入 15,182,894 B = 14.48 MB  (CI zip)
内层 ipa 15,225,989 B = 14.52 MB
主二进制 29,110,400 B = 27.76 MB
linux-rootfs.tar.gz 3,858,174 B = 3.68 MB，527 条目
汇总 31/31 通过
```

注意 rootfs 比 Alpine 官方 3.85 MB 略小是**正常的** ——
`COPYFILE_DISABLE=1` 去掉了 macOS 的 `._*` AppleDouble 冗余文件，
527 个真实条目一个不少。
